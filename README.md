# APS Industrial

Sistema de Planejamento e Programação da Produção Industrial desenvolvido para
auxiliar no gerenciamento de produtos, materiais, máquinas, operações,
ordens de produção e planejamento industrial.

## Objetivo

O APS Industrial tem como objetivo centralizar informações do processo
produtivo e auxiliar no planejamento e programação da produção.

## Tecnologias

### Backend

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- C#

### Frontend

- React 19
- TypeScript
- Vite
- Axios
- React Router
- Bootstrap
- Lucide React

## Arquitetura

O projeto está dividido em:

- IndustrialAPS.API
- IndustrialAPS.Domain
- IndustrialAPS.Infrastructure
- frontend

## Funcionalidades

- Dashboard
- Produtos
- Materiais
- Máquinas
- Operações
- Ordens de Produção
- Estrutura de Produto (BOM)
- Conexões entre máquinas
- Planejamento da produção
- Programação da produção
